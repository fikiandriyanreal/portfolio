# Fiki Andriyan — Portfolio

Personal portfolio of Fiki Andriyan, web designer & developer in Bali.

- `main` — current static site, live on GitHub Pages: https://fikiandriyanreal.github.io/portfolio/
- `astro` — migration in progress: Astro + EmDash CMS, target Cloudflare Workers (www.fikiandriyan.workers.dev)

The Astro site is an [EmDash](https://emdashcms.com) project: `npm run dev`, admin at `/_emdash/admin`.
