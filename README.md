# Portfolio - Fiki Andriyan

Website portfolio statis (HTML + CSS + gambar, tanpa build step).

## Isi
- `index.html` - halaman utama (hero biru, daftar 9 proyek, about, services, kontak)
- `style.css` - seluruh styling
- `shots/` - screenshot asli 9 website proyek

## Menjalankan
Buka `index.html` langsung di browser, atau hosting statis apa pun (GitHub Pages, Netlify, Vercel).

## Font
Tampilan memakai Fraunces (judul) dan Inter (teks) dari Google Fonts, dimuat lewat `<link>` di `index.html`. Versi preview Instinct memakai font internal hosting (Aime + KMR Melange Grotesk) yang tidak bisa disertakan di repo; Fraunces/Inter adalah padanan gratis terdekat - layout, ukuran, dan warna identik.
